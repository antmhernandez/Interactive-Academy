Investigating Motion with Measured Data

Name Date
Purpose: Collect and interpret position measurements, distinguish average velocity from acceleration, and judge whether a constant-acceleration model is reasonable.

Materials: tape measure, rolling object, smartphone or stopwatch, safe working area, notebook, graph paper or spreadsheet.

Safety: use a level, clear area away from traffic, stairs and hazards. Do not chase a moving object into unsafe areas.

1. Predict

If a rolling object speeds up, will its position increase by the same distance every second? Explain.

2. Measure

Choose a fixed origin and positive direction. Use video frames or equally spaced observations to record position at several times. Repeat the trial to improve consistency. Record what you actually observed, even if the data are imperfect.

3. Graph and analyze

  1. Make a position–time graph. Include labels and units on both axes.
  2. Calculate average velocity over each interval, using Δx/Δt.
  3. If the position data form a curve, try a quadratic model x(t) = A + Bt + Ct². Does the trend reasonably fit the observations?
  4. When acceleration is approximately constant, explain why B estimates initial velocity and 2C estimates acceleration. Include units.

4. Try a demonstration dataset

Simulated idealized data, not measurements: t (s) = 0, 1, 2, 3, 4 and x (m) = 0, 1, 4, 9, 16. What quadratic equation exactly fits these five points? What constant acceleration does it represent?

5. Interpret the experiment

Name one source of uncertainty in your measured data. Would repeating measurements, adjusting the timing, or improving the position reference help?
